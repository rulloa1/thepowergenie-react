# Video Studio

Mode: Operate. Implementation: code-first, for this app screen only; no standing workflow default is changed. Reference: the user's workflow diagram, translated into a usable editor rather than a static node canvas.

## Direction contract

THESIS: Turn the screenshot's generation pipeline into an editable short-video workspace, with the media and its current state visible together.

OWN-WORLD: Inherit Power Genie's navy, ice-blue controls, warm gold focus, system UI typography and restrained borders. Use color for pipeline stages and state. A preview-first composition is an extension of the existing application, not a site redesign.

STORY: Start from an idea, review the scenes, supply or generate media and narration, preview the result, and download a real video.

FIRST VIEWPORT: A compact application header, a horizontal pipeline, an idea and scene editor on the left, and a persistent portrait preview on the right. Primary actions sit beside their inputs. Settings opens a dedicated inline connection panel.

FORM: Standard editing workspace, pinned by the user's functional reference. Signature interaction: selecting a scene updates the portrait frame and timeline together. On mobile, an adjacent Preview scene link reveals the full frame, with a Back to scene link returning to the editor. No concept roll: this task applies the explicit new-work.md section 3 exception, “Never run the script for a local extension or a precisely specified narrow request; shape those directly.” The inherited system is preserved, and the screenshot supplies the functional pipeline. seed: none (unavailable).
